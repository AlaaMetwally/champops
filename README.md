# ChampOps

Championship Operations Platform.

ChampOps helps organizers run competitions with clear roles, schedules, scoring, and official sport rules.

## First sport

Inline Freestyle Skating (based on World Skate style regulations).

## Vision

Build a reusable championship platform that can start with one sport and grow to support more sports over time.

## Target users (application roles)

- Admin
- Coach
- Athlete
- Judge

## Technology direction

- Backend: Java + Spring Boot + Maven
- Frontend: Angular
- Database: PostgreSQL
- Cache: Redis (later)
- Containers: Docker
- Orchestration: Kubernetes (later)
- Architecture path: modular monolith first, then microservices

## Why this order

We start with a clear and simple foundation, then scale when the domain and boundaries are well understood.
This is a practical approach used in real-world systems.
